# dsh-baibao · 百宝

DSH 里的一个独立 Agent：有自己的性格、跨会话的长期记忆、安静的主动连接和独立设置。

> **早期开发版（M1 收尾 · M2 进行中）。** 现在可以从百宝面板打开原生对话，并在百宝工作区里聊天；记忆、推送和设置持久化尚未接入，界面会明确标注“规划中”。

## 计划中的能力

- **一个百宝，多个 thread**：人格与长期记忆共享，对话上下文按话题隔离。
- **长期记忆**：用户画像、事件、事实与偏好分层保存；可查看、纠正、删除。
- **安静主动**：规则快筛 + 语义判断，有具体结果时才提醒。
- **独立设置**：人格、模型、记忆和推送都在插件内配置。
- **与官方 Agent 一致**：复用 DSH 的 Agent Loop、工具、审批、沙箱和模型选择。

## 安装

需要已安装 DSH desktop profile。

```bash
npm install
npm run build
dsh plugin --profile desktop add <本仓库路径>
```

首次安装后重启一次 DSH，侧栏会出现「百宝」。

卸载：

```bash
dsh plugin --profile desktop remove dsh-baibao
```

## 使用

- 点击侧栏「百宝」进入对话页。
- 点击「开始对话」会在百宝工作区创建会话，并切到原生对话；百宝工作区的新对话默认使用「百宝」Agent 模式（人格 + 文件 + 终端）。
- 点击右上角齿轮进入设置面板，查看记忆、连接和通用设置。
- 在「设置 → 存储位置」里选择数据目录；更改目录会迁移 `memory/` 和 `config/`，成功后删除原目录数据。可以先点「创建备份」在默认目录保留一份，备份可随时删除。
- 百宝面板本身只做入口；记忆、推送和人格编辑会在后续版本接入。

## 开发

```bash
npm install
npm run dev      # 监听 src/，自动重建客户端 bundle
npm run check    # 类型检查 + 构建
```

修改 `src/client/**` 通常无需刷新页面；宿主侧改动可能需要重启 DSH。
