# dsh-baibao · 百宝

DSH 里的一个独立 Agent：有自己的性格、跨会话的长期记忆、安静的主动连接和独立设置。

> **早期开发版（M4 人格 v1 完成 · M3 LLM 巩固已接入）。** 现在可以从百宝面板打开原生对话，在百宝工作区里聊天，让百宝记住事实、偏好和片段，并用荣格四轴和可编辑的基础提示词调整它的性格。

## 计划中的能力

- **一个百宝，多个 thread**：人格与长期记忆共享，对话上下文按话题隔离。
- **长期记忆**：用户画像、事件、事实与偏好分层保存；可查看、纠正、删除。
- **安静主动**：规则快筛 + 语义判断，有具体结果时才提醒。
- **独立设置**：人格、模型、记忆和推送都在插件内配置。
- **与官方 Agent 一致**：复用 DSH 的 Agent Loop、工具、审批、沙箱和模型选择。

## 安装

需要已安装 DSH desktop profile。

```bash
npm install
npm run build
dsh plugin --profile desktop add <本仓库路径>
```

首次安装后重启一次 DSH，侧栏会出现「百宝」。

卸载：

```bash
dsh plugin --profile desktop remove dsh-baibao
```

## 使用

- 首页上方是「开始对话」Hero，下方是人格 / 记忆 / 连接 / 设置 tab。
- 「人格」tab 用荣格四轴雷达图调整百宝的能量来源、信息获取、决策方式和生活方式；分数表示倾向的清晰度（slight / moderate / clear / very clear），不是强弱。保存后新对话生效。
- 可以先选一个人格预设（均衡 / 直接 / 温和 / 安静 / 伙伴）作为基准，再手动微调；手动调整即脱离预设。配置存在结构性问题时会给出对应提示。
- 「基础提示词」决定百宝的身份与说话原则，可编辑、可重置，上限 600 字；四轴与预设只在此基础上调节语气。
- 点击「开始对话」会在百宝工作区创建会话，并切到原生对话；百宝工作区固定在 `~/.dsh/baibao/workspace`，新对话默认使用「百宝」Agent 模式。
- 「百宝」Agent 模式包含文件读写、终端、联网搜索、待办、子代理、计划模式、技能与目标管理等常用工具。
- 「设置 → 存储位置」只影响 `memory/` 和 `config/`，不会移动工作区。
- 在原生对话里说「记住……」或让百宝记住某个偏好；它会保存到长期记忆，并在之后的新对话中自动带上最近记忆。明确的「我喜欢/我讨厌/别……」也会被自动沉淀。
- 每轮对话结束后，百宝会按本轮内容刷新记忆召回，让下一轮带上更相关的条目。
- 在「设置 → 记忆整理模型」里选一个模型，百宝会在每轮对话后用 LLM 提炼长期事实（强制简体中文、按来源定权）；不选则用规则抽取，功能照常可用。
- 在首页「记忆」tab 里查看、搜索和删除已保存的条目：每页 10 条，超过一页才出现分页条；搜索同时匹配正文与标签。
- 在「设置 → 存储位置」里选择数据目录；更改目录会迁移 `memory/` 和 `config/`，成功后删除原目录数据。可以先点「创建备份」在默认目录保留一份，备份可随时删除。
- 首页只做入口和设置；推送会在后续版本接入。

## 开发

```bash
npm install
npm run dev      # 监听 src/，自动重建客户端 bundle
npm run check    # 类型检查 + 构建
```

修改 `src/client/**` 通常无需刷新页面；宿主侧改动可能需要重启 DSH。
